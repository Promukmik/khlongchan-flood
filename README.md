# น้ำท่วมแฟลตคลองจั่น — คู่มือเปิดเว็บจริง (Vercel + Supabase)

เว็บนี้ให้ **ทุกคนกดลิงก์จาก LINE แล้วแจ้งเหตุได้ทันที ไม่ต้องล็อกอิน** ข้อมูลขึ้นแผนที่ดาวเทียมแบบสดให้กู้ภัยและทีมอาสาเห็นพร้อมกัน

ใช้เวลาตั้งค่าประมาณ 30–45 นาที ใช้บริการแบบฟรีทั้งหมด ทำจากคอมพิวเตอร์จะง่ายที่สุด

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` `style.css` `app.js` | ตัวเว็บ |
| `config.js` | ที่ใส่รหัสเชื่อมฐานข้อมูล (แก้ไฟล์นี้ไฟล์เดียว) |
| `supabase.sql` | สร้างตารางฐานข้อมูล สิทธิ์ ที่เก็บรูป และตึกเริ่มต้น 29 ตึก |

---

## ขั้นที่ 1 · สมัคร 3 บัญชี

1. **GitHub** — https://github.com (เก็บไฟล์เว็บ)
2. **Supabase** — https://supabase.com (ฐานข้อมูลและที่เก็บรูป) กด Sign in with GitHub ได้เลย
3. **Vercel** — https://vercel.com (เปิดเว็บให้คนเข้า) กด Continue with GitHub ได้เลย

## ขั้นที่ 2 · สร้างฐานข้อมูลบน Supabase

1. ใน Supabase กด **New project**
   - ตั้งชื่อ เช่น `khlongchan-flood`
   - ตั้งรหัสผ่านฐานข้อมูล (จดเก็บไว้)
   - Region เลือก **Southeast Asia (Singapore)** จะเร็วที่สุด
2. รอให้โปรเจกต์สร้างเสร็จ (1–2 นาที)
3. เมนูซ้ายเลือก **SQL Editor** → **New query**
4. เปิดไฟล์ `supabase.sql` คัดลอกทั้งหมดไปวาง แล้วกด **Run**
   - ขึ้น Success = เรียบร้อย ได้ตาราง 29 ตึก ที่เก็บรูป และระบบอัปเดตสดแล้ว
   - รันซ้ำได้ ไม่ลบข้อมูลเดิม (ใช้ตอนอัปเดตเวอร์ชันด้วย)

## ขั้นที่ 3 · ใส่รหัสเชื่อมต่อใน `config.js`

1. ใน Supabase ไปที่ **Project Settings** แล้วหาส่วน **API** (บางเวอร์ชันแยกเป็น **Data API** กับ **API Keys**)
2. คัดลอก 2 ค่า:
   - **Project URL** — หน้าตาแบบ `https://xxxxxxxx.supabase.co`
   - **anon public key** (บางหน้าเรียก *publishable key*) — ตัวอักษรยาว ๆ
3. เปิด `config.js` ด้วยโปรแกรมแก้ข้อความ (Notepad / TextEdit) แล้ววางแทนที่:

```js
SUPABASE_URL: "https://xxxxxxxx.supabase.co",
SUPABASE_ANON_KEY: "วาง anon public key ตรงนี้",
```

> anon key เปิดเผยในหน้าเว็บได้ตามปกติ ความปลอดภัยคุมด้วยสิทธิ์ในฐานข้อมูลที่ตั้งไว้แล้ว **ห้ามใช้ service_role key** เด็ดขาด

## ขั้นที่ 4 · อัปโหลดไฟล์ขึ้น GitHub

1. ใน GitHub กด **New repository** ตั้งชื่อ เช่น `khlongchan-flood` แล้วกด **Create repository**
2. ในหน้า repo ใหม่ กดลิงก์ **uploading an existing file**
3. ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ลงไป (ใช้ `config.js` ที่แก้แล้ว)
4. กด **Commit changes**

## ขั้นที่ 5 · เปิดเว็บด้วย Vercel

1. ใน Vercel กด **Add New… → Project**
2. เลือก repo `khlongchan-flood` แล้วกด **Import**
3. Framework Preset เลือก **Other** แล้วกด **Deploy**
4. เสร็จแล้วจะได้ลิงก์ เช่น `https://khlongchan-flood.vercel.app`
5. กลับไป GitHub แก้ `config.js` ใส่ลิงก์นี้ในช่อง `SITE_URL` (กดไอคอนดินสอ แก้ แล้ว Commit)
   - Vercel อัปเดตเว็บให้อัตโนมัติภายใน 1 นาที
   - ต่อไปแก้ไฟล์ใน GitHub เมื่อไร เว็บจะอัปเดตเองทุกครั้ง

## ขั้นที่ 6 · ตั้งผู้ดูแลระบบ

ผู้ดูแลระบบทำได้: เพิ่ม/ลบตึก ย้ายตำแหน่งตึก ใส่เบอร์ติดต่อประจำตึก ลบรายงานหรือข่าวที่ไม่เหมาะสม และปิดเคสแทนได้

1. ใน Supabase ไปที่ **Authentication → Users → Add user → Create new user**
   - ใส่อีเมลและรหัสผ่านของผู้ดูแล ติ๊ก **Auto Confirm User**
2. คัดลอก **User UID** ของผู้ใช้นั้น
3. ไปที่ **SQL Editor** แล้วรัน (เปลี่ยนเป็น UID จริง):

```sql
insert into public.admins (user_id) values ('วาง-User-UID-ตรงนี้');
```

4. **ปิดการสมัครสมาชิกเอง:** ในหน้า Authentication ส่วนการตั้งค่า Sign In / Providers ปิดตัวเลือก **Allow new users to sign up** (ป้องกันคนแปลกหน้าสร้างบัญชี)
5. เปิดเว็บ กดปุ่ม **เจ้าหน้าที่** มุมขวาบน แล้วล็อกอินด้วยอีเมลที่สร้าง มุมขวาบนจะเปลี่ยนเป็น **ผู้ดูแลระบบ**

**เพิ่มผู้ดูแลคนอื่น:** ทำข้อ 1–3 ซ้ำ
**ถอนสิทธิ์:** รัน `delete from public.admins where user_id = 'UID';`

## ขั้นที่ 7 · ปรับตำแหน่งตึกให้ตรงดาวเทียม (ครั้งเดียว)

ตำแหน่ง 29 ตึกตั้งต้นเป็นค่าประมาณจากภาพหน้าจอ ต้องปรับให้ตรงภาพดาวเทียมจริงก่อน

1. ล็อกอินผู้ดูแล → กด **ผู้ดูแลระบบ** → **ปรับตำแหน่งทุกตึก (2 จุด)**
2. **จุดที่ 1:** เลือกตึกมุมหนึ่ง เช่น **อาคาร 5** (บนขวา) → กด **แตะตำแหน่งจริงบนแผนที่** → ซูมแล้วแตะกลางหลังคาตึกนั้น
3. **จุดที่ 2:** เลือกตึกอีกมุม เช่น **อาคาร 30** (ล่างซ้าย) แล้วทำแบบเดียวกัน
4. กด **คำนวณและบันทึกตำแหน่งทุกตึก** — ทั้ง 29 ตึกย้ายไปตำแหน่งใหม่พร้อมกัน
5. ตึกไหนยังคลาดเล็กน้อย: **ผู้ดูแลระบบ → แก้ไข (ตึกนั้น) → ย้ายตำแหน่ง**
6. ตึกที่ยังไม่มี เช่น อาคาร 6: **+ เพิ่มอาคาร → ปักบนแผนที่**

## ขั้นที่ 8 · ทดสอบก่อนประกาศ

- [ ] เปิดลิงก์จากมือถือ เห็นแผนที่ดาวเทียมและหมุดตึก
- [ ] แจ้งเหตุทดสอบ 1 รายการ พร้อมแนบรูป → ขึ้นในรายการและบนแผนที่
- [ ] เปิดเว็บอีกเครื่อง เห็นรายการเดียวกันขึ้นเองภายในไม่กี่วินาที
- [ ] เครื่องที่ 2 กด **รับเรื่อง** แล้วกด **ช่วยเหลือสำเร็จ** ได้
- [ ] เครื่องที่ 3 (ไม่ได้แจ้ง ไม่ได้รับเรื่อง) ต้อง **ไม่เห็น** ปุ่มปิดเคส
- [ ] รายงานระดับน้ำ ใส่เวลา ปักหมุดถนน → วงสีขึ้นบนแผนที่
- [ ] ผู้ดูแลลบรายการทดสอบทิ้ง

## เรื่องที่ควรรู้

- **Supabase แบบฟรีจะหยุดชั่วคราว** ถ้าไม่มีคนใช้งานประมาณ 1 สัปดาห์ ช่วงไม่มีน้ำท่วมให้เข้าเว็บบ้าง หรือเข้าหน้า Supabase กด Restore ก่อนฤดูฝน
- **เบอร์โทรในรายงานทุกคนเห็นได้** ตามที่ออกแบบไว้ให้กู้ภัยโทรกลับ ในฟอร์มมีข้อความแจ้งผู้แจ้งแล้ว
- **ปิดเคสได้เฉพาะผู้แจ้งหรือผู้ที่รับเรื่อง** ระบบจำจากมือถือเครื่องที่ใช้แจ้ง/รับเรื่อง ถ้าเปลี่ยนเครื่องหรือล้างข้อมูลเบราว์เซอร์ จะปิดเคสเองไม่ได้ ให้ทีมอื่นที่รับเรื่อง หรือผู้ดูแลระบบปิดแทน
- **ใครก็แจ้งและโพสต์ข่าวได้** ถ้ามีข้อมูลก่อกวน ผู้ดูแลลบได้ทันที
- **รูป** ถูกย่อบนมือถือก่อนส่ง (ไม่เกิน 1600 px) ที่เก็บรูปแบบฟรีมี 1 GB ใช้ได้หลายพันรูป
- **แผนที่ดาวเทียม** มาจาก Esri และแผนที่ถนนจาก OpenStreetMap (ใช้ฟรีสำหรับงานชุมชน)
- **สำรองข้อมูล:** กด **ผู้ประสบภัยรายอาคาร → ส่งออก CSV** เปิดด้วย Excel ได้

## แก้ปัญหา

| อาการ | วิธีแก้ |
|---|---|
| ขึ้นว่า "ยังไม่ได้เชื่อมฐานข้อมูล" | ตรวจ `config.js` ว่าใส่ URL และ key ครบ ไม่มีคำว่า YOUR เหลืออยู่ |
| "โหลดข้อมูลไม่สำเร็จ" | ตรวจว่ารัน `supabase.sql` แล้ว และโปรเจกต์ Supabase ไม่ได้หยุดชั่วคราว |
| ล็อกอินได้แต่ขึ้นว่าไม่มีสิทธิ์ผู้ดูแล | ยังไม่ได้รัน `insert into public.admins …` ด้วย UID ที่ถูกต้อง |
| อัปโหลดรูปไม่ได้ | รัน `supabase.sql` ซ้ำอีกครั้ง (สร้างที่เก็บรูป `photos`) |
| กด "ใช้ GPS" แล้วไม่ได้ | อนุญาตตำแหน่งให้เบราว์เซอร์ หรือกดปักหมุดบนแผนที่แทน |
| แก้ไฟล์แล้วเว็บไม่เปลี่ยน | รอ 1 นาที แล้วรีเฟรช ดูสถานะที่หน้า Vercel → Deployments |
